# Критическая энергия коллайдера NICA

Сергей Колокольчиков, ИЯИ РАН. Протонный режим коллайдера NICA.

Протоны в NICA нужно ускорить до 12.6 ГэВ. Критическая энергия кольца
\(\gamma_t = 7.09\) (5.7 ГэВ) лежит внутри этого диапазона. Вблизи неё коэффициент
скольжения \(\eta\) стремится к нулю: продольное движение теряет устойчивость,
слабеет затухание Ландау, растут нелинейные эффекты, падает порог
микроволновой неустойчивости. Как провести через \(\gamma_t\) охлаждённый интенсивный
пучок — предмет работ с 2020 года.

Рассмотрены два пути.

- Путь А: быстрый скачок \(\gamma_t\) квадруполями арок, пучок при этом в барьерном ВЧ.
- Путь Б: резонансная оптика арок, которая поднимает \(\gamma_t\) выше рабочей энергии.

Третий вариант — ускорять протоны выше \(\gamma_t\) ещё в Нуклотроне. Для него нужен
электронный охладитель на 3.1–6.8 МэВ, и в этой работе он подробно не разбирается.

Метод скачка проверен на синхротроне У-70 в ИФВЭ: моделирование совпало
с измерениями на сеансе.
